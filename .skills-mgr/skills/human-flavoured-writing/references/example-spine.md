# Example spine (product post)

Optional shape for a measured tool-comparison post. Adapt or omit sections for the actual
venue and evidence. Fill with real product facts; do not copy placeholder numbers.

```markdown
# <verb the change>: ~<N>% <scoped win>

<Pain in 1-2 lines. Concrete, not mission statement.>

<What you built in plain words. What stays the same for the user (UI, sandbox, etc.).>

Same <tiny task>, full payload (what you count):

<your tool demo>

Same edit without it (what model would write):

<baseline demo>

<One sentence: what lands on the model vs what the tool owns.>

Optional second demo only if it shows a different command pattern.

**Numbers:** <n sessions / requests, tokenizer, what was counted>.

| | tokens | / session | reduction |
| --- | ---: | ---: | ---: |
| your tool | … | … | |
| baseline | … | … | **~N%** |

<One sentence if rejects were zero or how you charge failures.>

I am **not** saying <overclaim>. <Net input / other cost in one breath>.
But <why the scoped win still matters for the reader (rate limit, price ratio)>.

Also <one limit of the comparison>. Fairer end-to-end would be <A/B shape>.

This is not <nearby category A> and not <nearby category B>. <One line each>.
You can stack them if useful.

**Try it:** <prereqs>.

\`\`\`sh
<2 commands max>
\`\`\`

<Config pointer + "full steps in README".>

<Reliability in 2-4 sentences max: grammar / atomic fail / real diff.>

<Optional: partial repair by index, only if it is a real differentiator.>

<Optional: how you built it, one short loop sentence, not a memoir.>

License + link.

Looking for real workloads and failure cases, not only wins. What would you throw at it?
```

## Cold-read targets for this spine

After filling, the cold reader should answer yes to:

1. I see the win in the first code pair.
2. I know what ~N% measures without scrolling back.
3. I can start a try tonight or I know exactly where the rest of the install is.
4. The middle did not turn into a design doc.
5. The ask at the end is specific (failures / workloads), not generic engagement bait.
