# Personal or organization profile README preset

## Reader and promise

Write for visitors deciding who the person or organization is, what they work on,
and whether to explore or make contact. The opening should sound like the subject,
not like product marketing.

## Default path

1. Name and concise focus
2. Current interests or work
3. Selected projects, capabilities, or communities
4. Useful evidence: links, demos, writing, or public activity
5. Preferred contact or collaboration path

## Evidence to gather

Use only information the subject has supplied or already made public for this
purpose. Verify project names, links, current status, and contact destinations.

## Fit checks

Keep the page scannable and personal. Select evidence rather than inventorying
every skill, badge, metric, or repository, and preserve the subject's preferred
voice and privacy boundary.
